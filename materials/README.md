# 比赛材料

这里保存 SC-SENTINEL 参赛时的项目文档与答辩演示文稿，供复盘和学习参考。

| 材料 | 推荐阅读方式 | 文件 |
| --- | --- | --- |
| 答辩 PPT | 初次了解项目时，先浏览选题、方案与成果的展示方式 | [查看或下载 PPTX](SC-SENTINEL-答辩PPT.pptx) · 约 23.1 MB |
| 项目文档 | 了解整体思路后，进一步阅读总体架构、核心技术与测试分析 | [阅读 PDF](SC-SENTINEL-项目文档.pdf) · 约 9.0 MB |

建议阅读顺序：**答辩 PPT → 项目文档 → [代码与运行说明](../code/README.md)**。如果希望参考现场演示的准备过程，可以继续阅读 [比赛演示手册](../code/docs/COMPETITION_RUNBOOK.md)。

两份资料共同介绍四层系统架构、五智能体级联审计、CWE 感知的 Harness 生成，以及 ASan、AFL++、eBPF 三源动态证据融合。五类智能体为依赖识别、漏洞假设、静态复核、验证工件和报告生成；PPT 中的“假设生成”对应文档中的“漏洞假设”。

GitHub 无法预览 PPTX 时，请下载后使用 PowerPoint 或其他兼容软件打开。

两份文件保留了比赛时的内容，仅供项目记录和学习参考，不属于仓库根目录 Apache License 2.0 的授权范围。

为保持首次上传目录完整，`code/SC-SENTINEL答辩ppt.pptx` 保留了同一演示文稿的原始副本。阅读时使用本目录的资料入口即可。
