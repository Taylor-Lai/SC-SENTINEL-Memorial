# 比赛材料

这里保存 SC-SENTINEL 参赛时的项目文档与答辩演示文稿，供复盘和学习参考。

| 材料 | 推荐阅读方式 | 文件 |
| --- | --- | --- |
| 答辩 PPT（展示版） | 固定比赛展示效果，适合直接阅读 | [查看或下载 PPTX](SC-SENTINEL-答辩PPT.pptx) · 约 23.1 MB |
| 答辩 PPT（源文件） | 查看原始文字与图形，便于研究和编辑 | [下载 PPT 源文件](SC-SENTINEL-可编辑版PPT.pptx) · 约 63.8 MB |
| 项目文档 | 了解整体思路后，进一步阅读总体架构、核心技术与测试分析 | [阅读 PDF](SC-SENTINEL-项目文档.pdf) · 约 9.0 MB |

建议阅读顺序：**答辩 PPT → 项目文档 → [代码与运行说明](../code/README.md)**。如果希望参考现场演示的准备过程，可以继续阅读 [比赛演示手册](../code/docs/COMPETITION_RUNBOOK.md)。

项目文档与答辩 PPT 共同介绍四层系统架构、五智能体级联审计、CWE 感知的 Harness 生成，以及 ASan、AFL++、eBPF 三源动态证据融合。五类智能体为依赖识别、漏洞假设、静态复核、验证工件和报告生成；PPT 中的“假设生成”对应文档中的“漏洞假设”。

参赛材料保留比赛时的方案与展示内容。阅读 PPT 第 7—16 页的流程图时，以下实现边界应以当前代码和[运行说明](../code/README.md)为准：

| 参赛材料中的流程或术语 | 当前仓库对应实现 |
| --- | --- |
| 源文件、ELF/PE 和共享库接入同一条 Harness 与三源验证流程 | 源码以 ZIP 或受支持的 Git 仓库提交，可进入五类智能体与可选的 ASan/AFL++ 动态验证；直接上传的 ELF/PE 文件只检查格式、依赖库与导入符号，不运行 Harness。单个源码文件需先打包为 ZIP。 |
| ASan、AFL++、eBPF 三源动态证据 | ASan/AFL++ 用于源码动态任务；eBPF 只在适用的专用 Linux 环境启用。报告按实际采集的证据裁决。 |
| `confirmed`、`need_review`、`unverified`、`untriggered` | Agent 中间产物使用这组动态状态术语；Web/API 报告使用 `confirmed`、`unverified`、`not_reproduced`、`false_positive`。 |

PPT 的成果数字和项目文档第五章的测试数字记录参赛时的样本与实验，不代表每次提交都会产生相同数量的 Finding、Harness 或运行证据。

GitHub 无法预览 PPTX 时，请下载后使用 PowerPoint 或其他兼容软件打开。展示版每页为固定图片；源文件保留原始文字、图形与嵌入字体，两版均为 19 页。源文件第 7 页的架构图排布与输入、输出标签略有不同，第 15 页标题明确写出 eBPF 反向纠错，其余核心技术和成果数字保持一致。

源文件使用 Git LFS 保存，克隆后执行 `git lfs pull` 下载完整文件。不同软件的字体和矢量图渲染可能存在差异，查看比赛展示效果时推荐展示版。
