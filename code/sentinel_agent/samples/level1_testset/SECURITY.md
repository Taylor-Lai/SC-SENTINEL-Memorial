# 安全说明

## 故意保留漏洞的代码

本目录中的每个程序都至少包含一个刻意设置的内存安全缺陷。测试集仅用于评估静态分析器、模糊测试工具、运行时检测器与审计工具的检测能力。

请勿：

- 将测试集中的二进制程序部署到生产环境；
- 通过网络套接字公开这些程序；
- 在实际应用中复用其中的漏洞代码模式；
- 在保存敏感数据的机器上使用这些程序处理不可信输入。

## 问题反馈

样本中的预设漏洞不适用常规 CVE 报告流程。如果发现 [CWE 矩阵](docs/CWE_MATRIX.md) 未覆盖的非预期缺陷，请提交 Issue，说明缺陷模式与受影响文件。
